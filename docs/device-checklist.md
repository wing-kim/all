# 실기기 확인 목록 (아이폰·안드로이드·퀘스트, 1102.s)

자동 점검(`node photoreal/tests/qa.mjs`)은 맥의 헤드리스 크롬으로 기기를 흉내 냅니다. 화면 크기, 터치, 겹침, 자동 화질 단계, WebGL2 없는 경우는 흉내로 확인했지만, 기기 고유의 그래픽 처리와 메모리 한도는 실제 기기에서만 알 수 있습니다. 아래 목록은 흉내로 확인한 것과 실기기에서 봐야 하는 것을 나눠 적은 것입니다.

미리보기 주소는 `https://evyfjae.github.io/kapehorn-preview/xr-photoreal/new/3d-model.html` 이고, 짧은 주소는 `https://evyfjae.github.io/kapehorn-preview/vr` 입니다. 오른쪽 설정의 보기 방식에서 '렌더'를 누르면 실사 3D 가 켜집니다(주소 끝에 `?pr=1` 을 붙이면 바로 렌더로 열림).

## 실기기에서 봐야 하는 것

| 기기 | 어디서 | 무엇을 보나 | 왜 실기기인가 |
|---|---|---|---|
| 아이폰(사파리) | 위 주소를 열고 보기 방식 '렌더' | 1분 넘게 둘러보고 층을 오가도 탭이 다시 열리지 않는지(iOS 탭 메모리 한도) | 크롬 흉내에는 iOS 메모리 한도가 없음 |
| 아이폰 | 렌더, 외관과 실내 1층 | 주변 건물·바닥 텍스처가 흐리거나 검게 나오지 않는지(KTX2 → ASTC/ETC 변환) | 텍스처 압축 형식은 기기 GPU 가 정함 |
| 아이폰 | 세로·가로 돌리기, 주소창이 접히고 펴질 때 | 아래쪽 실사 패널과 나침반이 홈 바·주소창에 가리지 않는지 | 사파리 주소창 높이 변화는 흉내로 재현되지 않음 |
| 아이폰 | 실내 걷기 | 두 손가락 벌리기·오므리기로 확대·축소, 바닥 누르기로 이동 | 실제 터치 제스처 |
| 안드로이드(크롬, 중급 기기) | 렌더 외관 | 처음 뜨는 시간(4G 기준 목표 12초 안), 둘러볼 때 끊김 | 기기 성능 |
| 안드로이드 | 품질 '자동' | 패널의 품질 표시가 기기에 맞게 '보통'이나 '낮음'으로 내려가는지 | 자동 화질은 실제 프레임 시간으로 정함 |
| 퀘스트 3 | `/vr` → VR 로 들어가기, 탭 세 개(현황·신축·③ 실측) × 스케치업·렌더 | 들어가기, 순간이동, 층 이동, 손목 메뉴가 모두 되는지 | 실제 컨트롤러 |
| 퀘스트 3 | 렌더로 외관과 실내 | 72fps 유지(끊김 없음), 오래 있어도 탭이 다시 열리지 않는지 | 기기 GPU·메모리 |
| 퀘스트 3 | 주변 벽돌·석재 건물, 신사중 운동장 | VR 에서도 텍스처가 보이는지(VR 아틀라스) | 기기 텍스처 형식 |
| 퀘스트 3 둘 이상 | 멀티플레이 | 음성 에코, 3명 이상 접속 | 실제 네트워크·오디오 |

확인한 결과는 기기 이름, 운영체제 판, 브라우저와 함께 알려 주시면 다음 판에 반영합니다.
