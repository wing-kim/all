## Jack 실기기 확인 목록

1. 휴대폰·퀘스트 2D 에서 바닥(차선·타일 줄눈·마루)이 아직 자글거리는지. 자글거리면 기기·바닥·거리 알려 주기.
2. 퀘스트 VR 에서 72fps(`?pr=1&prfps=1`, VR 시야 프레임 판), 5층 사무실 가구 윤곽 깜빡임.
3. 첫 방문(회사망·LTE)과 다시 방문 체감 시간. 첫 방문 12초를 위해 가구를 실내 진입 때 받게 바꿀지 결정.
4. 야간: 우리 건물이 이웃보다 밝게 보이는지, 가로등 빛 웅덩이 크기·색.
5. 석양 하늘 밝기(0.6 으로 낮춤), 유리 하늘 반사, 하늘 사진 방향 바뀐 뒤 낮 외관 인상.
6. 외장 시안 자동 처방(우드 루버·테라코타 등)의 질감과 색이 어색한 시안이 있는지.
7. 지하 주차 번호(노란 두 자리, 입구 앞 통로)와 정지선, 1층 카페 의자 색, 사무실 층별 의자 색.
8. 7층(PH1 → 7층)·8층(층수 8) 실내 가구와 조명, 비기본 주차×1층 조합 1층 조명.
9. 멀티플레이: 퀘스트 2D 브라우저에서 버튼이 보이는지, 회사망·LTE 연결.
