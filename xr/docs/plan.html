0. 이 문서 쓰는 법

이 문서는 케이프혼타워 WebXR 작업의 기준 문서입니다. 사람과 AI 에이전트 모두 작업을 시작하기 전에 이 문서를 처음부터 읽고, 작업을 마치면 8장의 상태 표시와 14장의 진행 기록을 고칩니다. 이 문서와 코드가 다르면 코드를 직접 확인하고, 차이를 진행 기록에 남긴 뒤 문서를 고칩니다.

상태 표시는 네 가지입니다. 완료 진행 중 대기 막힘. 체크리스트 항목은 끝나면 <li data-done>로 바꿉니다.

1. 요약

Wing이 계속 발전시키고 있는 케이프혼타워 3D 웹뷰(new/3d-model.html)를 Wing 파일을 한 줄도 고치지 않고 메타 퀘스트 3에서 실제 크기 몰입 VR과 패스스루 피규어로 볼 수 있게 만듭니다. 지니가 새로 만드는 모델은 Wing이 뷰어에 올리고, XR은 그 결과를 자동으로 이어받습니다. PC와 모바일 사용자는 지금과 똑같은 화면을 봅니다.

원칙 1. Wing 무수정

XR 계층은 별도 폴더 xr/에만 둡니다. Wing의 HTML을 그대로 불러와 실행 직전에 XR 기능만 끼워 넣습니다.

원칙 2. Wing 기능 자동 반영

XR 메뉴는 Wing 화면의 버튼과 입력을 읽어 만듭니다. Wing이 기능을 추가하면 XR 메뉴에도 바로 나타납니다.

원칙 3. 같은 웹, 기기별 모드

같은 페이지가 PC와 모바일에서는 기존 3D로, 퀘스트에서는 VR 버튼과 피규어 버튼이 추가된 형태로 열립니다.

현재 위치

P0 완료 기술 스파이크를 마쳤습니다. Wing 원본을 고치지 않고 VR 진입, 패스스루 피규어, Wing 메뉴의 공간 패널 미러, 성능 최적화(그리기 호출 90% 감소)까지 에뮬레이터에서 확인했습니다(커밋 b521cee). 다음은 P1 실기기 기준선입니다. 퀘스트 3를 연결해 실제 프레임 수치와 입력을 측정합니다.

XR 설계에 영향을 주는 사실

  • 앱 코드 전체가 즉시 실행 함수(IIFE) 하나 안에 있어 renderer, scene, camera, 상태 변수가 밖으로 노출되지 않습니다. 밖에서 볼 수 있는 것은 window.CH(state), window.PH(사진 뷰어), THREE 정도입니다.
  • 설계 조합을 바꾸면 build()가 건물 메시를 모두 지우고 다시 만듭니다. 그래서 XR 쪽은 특정 메시를 붙잡지 않고, 매번 장면을 다시 읽어야 합니다.
  • Wing은 GitHub 웹 업로드로 main에 파일을 통째로 덮어쓰는 방식으로 일합니다. 구조가 예고 없이 바뀔 수 있으니 XR 쪽에 자동 호환 점검이 필요합니다(P2).
  • Wing 장면은 PC에서 프레임당 그리기 호출이 약 3,280회, VR 양안에서 약 6,700회입니다. 퀘스트 3 권장치(200회 미만)를 크게 넘습니다. 그래서 XR 쪽 최적화가 필수입니다(6장, P6).

P0. 기술 스파이크 완료

Wing 무수정 구조로 XR 핵심 기능이 가능한지 확인합니다.

  • 래퍼와 주입 구조(xr/index.html, xr/kh-xr.js)
  • VR 진입, Wing 시점 따라가기, 컨트롤러 이동
  • 패스스루 피규어(절두체 보정, 디오라마 자르기, 스틱과 두 손 크기 조절)
  • Wing 메뉴 공간 패널 미러와 클릭 실행
  • 병합 프록시 성능 측정

P1. 실기기 기준선 다음

퀘스트 3에서 스파이크를 그대로 돌려 실제 수치를 얻고, 개발과 미리보기 경로를 고정합니다.

  • 퀘스트 3 USB 연결, adb reverse tcp:8790 tcp:8790로 http://localhost:8790/xr/ 열기(보안 컨텍스트 확보)
  • VR과 피규어 진입 성공, 컨트롤러와 핸드 입력 동작 확인
  • 외부, 내부, 렌더 모드 각 30초 프레임 시간 기록(OVR Metrics 또는 performance.now 로그)
  • Quest 브라우저에서 XR 중 window rAF 동작 확인(Wing 루프가 XR 프레임에서만 도는지)
  • 미리보기 배포 경로 확정(13장 결정 1)

완료 조건: 위 다섯 항목 결과를 14장에 숫자로 기록. 사람 확인: Jack 착용 5분, 멀미와 크기감 메모.

P2. XR 코어 안정화 대기

Wing이 파일을 바꿔도 깨지지 않고, 실패하면 원본 화면은 그대로 남게 합니다.

  • 주입 위치를 찾지 못하면 원본을 그대로 띄우고 XR 버튼만 숨김(현재는 오류 문구)
  • 세션 진입과 종료 10회 반복 후 PC 화면 상태(카메라, 배경, 표시 상태) 완전 복원
  • 자동 스모크 테스트 xr/tests/smoke.mjs: 원본 최신본 로드, 후킹 5종 확보, 에뮬레이터 VR과 AR 진입, 패널 그룹 수, 콘솔 오류 0 확인
  • Wing main이 바뀌면 스모크 테스트를 돌리는 절차를 12장에 기록(필요하면 GitHub Actions 무료 범위에서 자동화)
  • 오류 로그를 패널 하단에 표시하는 디버그 모드 ?debug=1

P3. 공간 UI 대기

Wing의 모든 메뉴를 XR에서 읽기 쉽고 누르기 쉽게 만듭니다.

  • 탭 구성 확정: 시점, 층, 외관, 내부, 빛과 시간, 표시, 사진, 설정. Wing 그룹 이름을 탭에 매핑하는 표를 코드에 두고, 매핑에 없는 새 그룹은 "기타" 탭에 자동 추가
  • 누락 컨트롤 수집: 층 칩 #floorChips, 색상 견본, 날짜와 시각 입력, 겹쳐 보기 단계
  • 글자 품질: 패널 캔버스 2배 해상도, 1m 거리에서 글자 높이 1.5cm 이상, 한글 글꼴 지정
  • 현재 선택 상태 강조(라디오와 토글), 실행 중 표시
  • 패널 위치: 왼손에 붙이기와 공간에 고정 전환, 손목 미니 메뉴(피규어 전용)
  • 3D 라벨: 층 이름과 면적 라벨을 XR에서 보이게(방법은 13장 결정 3)
  • 실사 사진 패널: window.PH.man 카탈로그로 현재 시안과 층의 사진을 큰 액자로 표시

P4. VR 이동과 편안함 대기

실제 크기로 건물 안팎을 편하게 돌아다닙니다.

  • 텔레포트 포물선과 착지 표시, 바닥이 아닌 곳은 불가 표시
  • 스틱 걷기를 Wing 걷기 입력으로 넘겨 벽, 기둥, 램프 충돌과 층 전환을 재사용(키 이벤트 합성 방식 검증). 안 되면 자체 레이캐스트 충돌
  • 시점 프리셋과 층 이동은 짧은 페이드로 전환
  • 편안함 설정: 스냅 회전(기본 30°)과 부드러운 회전, 이동 중 시야 가장자리 어둡게
  • 바닥 높이 일치: 실제 바닥과 가상 바닥 차이 5cm 이내

P5. 패스스루 피규어 대기

책상 위 모형을 자연스럽게 놓고 돌려 보고, 그 안으로 들어갑니다.

  • 평면 인식으로 책상이나 바닥 위에 배치. 평면이 없으면 손 앞 0.5m에 띄움
  • 두 손 그립으로 크기와 회전, 한 손 그립으로 이동. 크기 범위 1:20에서 1:1000, 배율 칩 표시
  • 범위 선택: 건물만, 건물과 블록(기본 45m), 미성아파트 포함
  • 모형 아래 받침 원판과 그림자
  • 앵커로 다음 접속 때 같은 자리에 복원
  • "안으로 들어가기": 같은 세션에서 손으로 가리킨 지점으로 1:1 전환(주변을 불투명 환경으로 채움), "피규어로 돌아가기"

P6. 성능 대기

퀘스트 3에서 모든 모드가 72fps를 유지합니다.

  • 비슷한 재질(같은 종류, 색, 맵, 투명도) 묶기로 그리기 호출 200회 미만 목표
  • 그림자 맵 해상도와 범위를 XR용으로 조정, 피규어에서는 받침 그림자만
  • 프레임버퍼 배율과 고정 포비에이션 조정(r128 지원 범위 확인)
  • 렌더 모드의 환경맵, 야간 조명 비용 측정과 상한 설정
  • 10분 연속 사용 메모리 측정, 원본 재생성 반복 시 누수 없음

P7. 지니 모델 통합 대응 대기

지니 모델이 Wing 뷰어에 들어온 뒤에도 XR 품질과 성능을 유지합니다.

  • 모델 규격서 전달(10장): 미터 단위, 재질 수 제한, 층과 부위별 병합, KTX2 텍스처, 조명 베이크
  • Wing 통합본으로 스모크 테스트와 성능 재측정
  • 모델 로딩 중 XR 진입 시 대기 표시

P8. 비전 프로 확장 대기

같은 주소에서 비전 프로 몰입 VR을 지원합니다.

  • immersive-vr 진입, 시선과 핀치(transient-pointer)로 패널 조작
  • 피규어는 VR 안 가상 테이블 위에 표시(비전 프로 Safari는 패스스루 WebXR 미지원)
  • (검토) Safari <model> 요소로 USDZ 조합을 실제 방에 꺼내 보기
