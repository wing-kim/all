# 케이프혼타워 모델 납품 규격 (지니님께)

작성 2026-10-30, 대상: 지니님(모델링), Wing님(뷰어 통합)

## 이 문서의 목적

지니님이 새로 만드시는 건물 모델은 Wing님의 3D 웹뷰(`new/3d-model.html`)에 올라가고, 퀘스트 VR과 패스스루 피규어 화면은 그 웹뷰를 그대로 이어받아 보여 줍니다. 그래서 XR을 위한 별도 모델은 필요 없습니다. 다만 퀘스트는 휴대용 기기라서, 아래 규격을 지켜 주시면 VR에서 끊김 없이 볼 수 있습니다. 규격은 지금 Wing 웹뷰를 퀘스트용으로 최적화하면서 실제로 잰 값을 바탕으로 정했습니다.

## 파일 형식과 좌표

- 형식은 GLB(glTF 2.0 바이너리) 하나로 부탁드립니다. 조합이 많으면 시안별로 파일을 나눠도 됩니다.
- 단위는 미터이고, Y축이 위쪽입니다.
- 원점은 대지 기준점으로 맞춰 주세요. Wing 웹뷰의 기준(1층 평면 이미지에서 41.6픽셀이 1미터, 원점은 픽셀 좌표 914, 770)과 같으면 기존 도로와 주변 건물에 바로 맞습니다. 다르게 잡으셨다면 원점 위치를 Wing님께 알려 주세요.
- 1층 바닥 높이는 0.07미터입니다(현재 웹뷰 기준).

## 나누는 단위와 이름

- 층별로 나눠 주세요. 이름은 `B3`, `B2`, `B1`, `1F`에서 `7F`, `PH1`, `PH2`, `ROOF`처럼 웹뷰의 층 이름과 같게 하면 층 이동과 연결하기 쉽습니다.
- 한 층 안에서는 외피, 내부 벽과 바닥, 가구, 조명기구 정도로 나눕니다.
- 바꿔 끼우는 조합 요소는 앞에 종류를 붙여 이름을 정합니다. 예를 들어 외관 시안은 `EXT_stack`, `EXT_brick`, 실내 시안은 `INT_cafe_A`, `INT_cafe_B`, 조명 세트는 `LIGHT_warm`, `LIGHT_cool`입니다. 시안 이름은 사진 저장소(kapehorn-media)의 시안 키(stack, veil, arch 등)와 맞추면 실사 사진과도 자동으로 연결됩니다.

## 성능 예산 (퀘스트 3 기준)

| 항목 | 기준 | 이유 |
|---|---|---|
| 재질 종류 | 건물 전체 30종 이내 | 재질 수가 곧 그리기 호출 수로 이어집니다. 퀘스트 권장은 프레임당 200회 미만입니다 |
| 같은 재질 메시 | 층마다 하나로 합치기 | 메시가 잘게 나뉘면 그리기 호출이 늘어납니다 |
| 삼각형 수 | 건물 전체 50만 이내(주변 포함 100만 이내) | 퀘스트 권장 150만 미만에서 여유를 둡니다 |
| 텍스처 | KTX2(Basis) 압축, 한 장 2048픽셀 이하 | 메모리와 대역폭을 줄입니다 |
| 형상 압축 | Draco 또는 Meshopt | 내려받는 시간을 줄입니다 |
| 조명 | 실내는 라이트맵으로 굽기 | 실시간 조명은 퀘스트에서 비쌉니다 |
| 투명 재질 | 유리 등 꼭 필요한 곳만 | 겹친 투명면은 같은 화소를 여러 번 그립니다 |

## 시간대와 조명

외부 시간대(오전, 오후, 석양, 밤)는 웹뷰의 하늘과 태양으로 바뀝니다. 실내를 라이트맵으로 구우실 때는 낮 기준 한 벌을 기본으로 하고, 밤 분위기가 중요하면 밤 기준 라이트맵을 한 벌 더 주시면 시간대에 맞춰 바꿔 끼우겠습니다.

## 비전 프로까지 고려한다면

비전 프로의 Safari는 웹 페이지의 3D 모델을 실제 방으로 끌어내 볼 수 있는데, 이때는 USDZ 형식이 필요합니다. 같은 모델을 조합별 USDZ로도 내보낼 수 있으면(블렌더의 USD 내보내기) 나중에 이 기능을 붙이기 쉽습니다. 지금 당장은 필요하지 않습니다.
