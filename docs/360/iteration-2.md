# 360° 시각화 — 실사 품질 개선 2차 기록

2026-10-15. 초기 검증 보고서는 [assessment.md](assessment.md)에 보존한다. 이번 기록은 완성된 실사 재현을 선언하는 문서가 아니다. 현재 실사 원본과의 차이, 특히 주변 건물의 세부 형상과 도시 밀도는 계속 개선할 대상이다.

## 현재 구현

- 기존 Three.js r128 모델 생성 코드를 구조 기준으로 유지한다. 새 렌더러는 같은 정점·변환을 복사해 사용한다. AI 이미지에 맞추려고 코어 벽이나 층고를 바꾸지 않는다.
- 지원 브라우저에서는 Three.js 0.186.1 + three-gpu-pathtracer 0.0.27의 WebGPU 광선 추적을 사용한다. Open Image Denoise를 브라우저 안에서 실행한다. 서버 GPU, 유료 서비스, 모델 업로드는 사용하지 않는다.
- 이동 중과 정밀 계산 중에는 같은 장면의 실시간 렌더를 표시한다. 노이즈 제거가 끝난 정지 화면만 정밀 결과로 표시해, 몬테카를로 노이즈가 지면 깜빡임처럼 보이는 일을 줄인다.
- WebGPU가 없으면 기존 WebGL 실시간 경로를 사용한다. 두 경로 모두 실제 연속 3D이며, 원본 비교 이미지의 각도 전환은 오른쪽 비교 패널에만 적용한다.
- 유리 투과, 주변 장면 반사, 실내 면광원, 표면 법선·거칠기, 하늘 배경, 외벽·창 프레임·블라인드·실외기·상가 창호·옥상 설비, 포장·연석·배수구를 추가 또는 개선했다.
- 도면 방위 화살표를 새 뷰어에서 숨겼다. 기존 도면 뷰는 보존했다. 도로/보도/대지의 높이를 분리하고 중복 구형 차선 메시를 제거했다.
- Poly Haven 수목과 PBR 재질, Car Concept 차량을 재사용했다. 수목은 잎 단위 샘플링, 실루엣 조정, 메시 단순화와 Draco 압축을 거쳤다. 출처·라이선스는 [assets/README.md](../../new/360/assets/README.md)에 있다.
- 주변 아파트는 기존 코드의 현황 그룹을 사용한다. 장래 재건축 가정을 기본 장면에서 제외했다. 새 원경은 예시 도시 모델이며 현장 측량 자료로 주장하지 않는다.
- 앞/뒤/좌/우/코너/조감도, 드래그 회전, 휠 확대, 자동 회전, 주변 건물 표시, 비교 패널, GLB 저장을 제공한다.

## 확인한 검증

독립적인 원형 모델(`?lab=verify`, alt4)과 개선 모델을 비교했다. 원래 부재 3,234개, 위치 정점 119,173개 및 로컬 변환을 대상으로 1e-4 단위의 FNV 형태 해시를 계산했으며 두 모델 모두 **3710930476**이었다. 정적 배칭으로 추가한 렌더 메시를 제외하고 원형 부재를 비교했다. 이 검사는 설계 인증이 아니라 코드에서 형상을 보존했는지 확인하는 검사다.

[여섯 방향 검사](evidence/cinema-view-tests.json)는 모든 시점에서 같은 형태 해시, 카메라 반경 62m, 원형 카메라와 정밀 카메라의 위치 일치를 확인했다. [실제 마우스 드래그 검사](evidence/cinema-drag.json)는 32개 입력 구간에서 약 399.6°의 연속 회전을 기록했다.

`npm ci --ignore-scripts`와 `npm run build`를 고정 버전 잠금 파일로 검증했다. 최초 잠금 파일의 플랫폼 경로 문제를 수정한 뒤 재실행하여 통과했다. JavaScript 구문 검사와 `git diff --check`도 통과했다. 면광원 보조 렌더의 LTC 초기화 오류는 라이브러리 초기화를 추가해 해결했다.

[입력·내보내기 검사](evidence/cinema-interaction.json)에서 마우스 휠로 카메라 반경이 62m에서 58.9m로 감소했고, 주변 건물 숨김 시 정밀 장면의 해당 메시가 모두 숨겨지는 것을 확인했다. 형상 GLB는 6,275,104바이트이며 glTF 2.0 매직·버전·파일 길이가 일치했다.

수목 밀도 시험 중 기본 WebGPU 저장 버퍼 한도 문제가 발생했다. 어댑터가 지원하는 범위 안에서 최대 512MiB의 버퍼 한도를 요청하도록 변경했다. 이는 해당 메모리를 선할당한다는 의미가 아니다. 잎을 68% 보존하고 메시를 20%로 단순화하여 수관 밀도와 기하 복잡도를 분리했다. 최종 장면은 다시 48샘플 수렴과 노이즈 제거를 완료했다. 비동기 GPU 검증 오류가 발생하면 실시간 렌더로 돌아가도록 처리했다. 이동 화면의 유리에는 같은 장면에서 촬영한 반사 큐브맵을 사용한다.

화면 크기 변경 검사에서 노이즈 제거용 보조 렌더의 굴절 버퍼가 이전 크기를 참조하는 오류를 발견했다. 알베도·법선 가이드 버퍼를 계산할 때 불필요한 굴절 패스를 끄도록 수정했다. 1440px 검사 화면에서 실제 창 크기로 돌아간 뒤에도 48샘플 수렴·노이즈 제거가 다시 완료됐고, 새 GPU 오류가 없었다.

원경에는 ambientCG Facade 018 A(CC0)의 벽돌·유리 PBR 재질을 추가했다. 가로수 식재 경계, 모서리를 깎은 연석, 주변 건물 옥상 표면도 보완했다. 주광과 환경광 비율은 화면 비교 후 조정했으며, 넓은 화면에서는 OIDN 정식 크기 가중치(1.84MB), 좁은 화면에서는 소형 가중치를 사용한다. 정식 크기 가중치로도 48샘플 수렴과 노이즈 제거 완료를 확인했다.

이동 중 실시간 표시에는 깊이 기반 GTAO, 공간 노이즈 제거와 FXAA를 적용했다. 굴절 유리의 이동 화면과 정지 화면 사이 밝기 차이를 줄이기 위해 실시간 드로우에서만 유리 색을 보정하며, 원형 재질과 광선 추적 재질은 유지한다. 주변 현황 아파트에도 창 프레임과 옥상 재질을 추가하되 상가 디테일은 적용하지 않는다. [후면 비교](evidence/cinema-back.png)에서 48샘플 및 노이즈 제거 완료를 확인했다. 원본 AI 이미지의 고층 재건축 배경과 달리 현황 아파트를 표시한다.

## 시각적 판단과 남은 작업

[정밀 코너 비교](evidence/cinema-corner.png)는 초기 화면보다 하늘, 유리, 간접광, 접촉 그림자, 포장, 차량과 수목이 개선됐음을 보여준다. 원본 실사와 동등한 수준이라고 판정하지 않는다. 근거리 도시의 창호·상가 디테일, 원경의 다양성, 지면의 자연스러운 사용 흔적이 여전히 부족하다. AI 원본의 잘못된 면이나 부재 위치를 복제해 차이를 줄이지 않는다.

정밀 렌더는 장치와 화면 크기에 따라 수렴 시간이 달라진다. 표시되는 샘플 수와 노이즈 제거 완료 상태를 확인할 수 있다. 정지 후 계산 시간이 있다는 점은 실시간 조작 가능 여부와 별도로 평가한다. 이동 중에는 같은 장면의 실시간 표시를 유지한다. 390px 반응형 배치와 WebGL 호환 모드를 검사했다. 좁은 화면은 비교 이미지를 접고 균형 품질로 시작한다. 이 검사는 데스크톱 브라우저 에뮬레이션이며 모바일 실기기 성능 검증은 아니다. 장시간 GPU 메모리 사용량과 배포 후 캐시/네트워크 동작도 추가 검증 대상이다.

## 실행과 재현

로컬 서버 실행 시 [기본 뷰어](http://127.0.0.1:8765/new/360/), [정밀 보기](http://127.0.0.1:8765/new/360/?engine=cinema), [WebGL 실시간 보기](http://127.0.0.1:8765/new/360/?engine=realtime)를 사용할 수 있다. localhost 링크는 이 컴퓨터에서만 동작한다. GitHub Pages 공개 경로 반영 여부는 PR/배포 상태와 별도로 확인해야 한다.

렌더러 빌드: `tools/360/`에서 `npm ci --ignore-scripts`, `npm run build`. 정적 번들은 `new/360/modern.js`이며 Pages에서 실행에 Node 서버가 필요하지 않다. 수목 가공 스크립트는 `tools/360/prepare_tree.py`이며 Blender에 `-- 원본.gltf 출력.glb` 인자를 전달한다.

기술 근거: [three-gpu-pathtracer](https://github.com/gkjohnson/three-gpu-pathtracer), [Poly Haven 라이선스](https://docs.polyhaven.com/en/faq), [Car Concept](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept), [OIDN 가중치](https://github.com/RenderKit/oidn-weights). 이미지 기반 재구성을 선택하지 않은 이유는 초기 보고서의 다중 시점 일관성 검토를 따른다.

GitHub 변경은 `codex/tower-360-validation` 전용 브랜치와 초안 PR #1에서 관리한다. `main` 직접 수정이나 병합은 수행하지 않았다.

추가 표면 개선: 주변 건물의 위치에서 결정되는 고정 색상 변주를 적용해 모든 외벽이 같은 흰색으로 보이는 문제를 줄였다. 도로 보수 포장 3곳과 맨홀 4곳을 별도 높이로 추가했다. 보수 포장 상단은 0.012m, 맨홀 상단은 0.022m로 기존 차선(0.045m)보다 낮다. 실제 위치를 측량한 시설물은 아니며 주변 환경의 예시 디테일이다. 754px 실제 창 크기에서 32샘플 수렴과 노이즈 제거 완료 화면을 확인했다. 본 건물 생성 코드는 이 변경에서 수정하지 않았다.

실내 개선: 반복되는 책상 일부를 라운지 좌석과 모니터가 있는 작업 공간으로 교체하고, CC0 목재 PBR 재질을 적용했다. 가구와 조명 배치는 예시이며 확정 실내 설계가 아니다. 본 건물 부재는 유지했다.

기본 품질 판정 수정: 850px 이하라는 이유만으로 데스크톱 창까지 경량 렌더를 사용하던 조건을 수정했다. 이제 좁은 화면과 거친 포인터 입력 조건이 함께 맞는 터치 환경만 32샘플·0.8 렌더 배율·소형 OIDN으로 시작한다. 그 외에는 64샘플·원배율·정식 OIDN으로 시작하며 품질 선택으로 변경할 수 있다. 앞선 32/48샘플 검증 기록은 당시 설정의 이력이다.

[754px 데스크톱 고품질 검증](evidence/cinema-desktop-high.png): 품질 high, renderScale 1, 최소·최대 샘플 모두 64, OIDN 완료를 확인했다. 해당 실행의 새 콘솔 오류는 없었다. 이전 균형 화면보다 창호 경계와 수목의 선명도가 개선됐다.

우측 시점 재검증: 낮은 기존 우측 시점은 이웃 건물 지붕이 타워 하부를 가렸다. 방위와 62m 반경을 유지하고 높이를 올려 하부까지 볼 수 있도록 했다. [우측 화면](evidence/cinema-right-elevated.png), [형상·카메라 재검사](evidence/cinema-right-retest.json)에서 형상 해시 3710930476 유지, 두 렌더러 카메라 일치, 64샘플 및 노이즈 제거 완료를 확인했다. 이 기록이 이전 여섯 시점 검사 중 우측 카메라 좌표를 대체한다. 주변 건물 일부에는 수평 연속창과 층별 돌출 띠를 적용해 반복을 줄였다.

배포 확인: GitHub Pages는 현재 main 루트를 배포한다. 전용 브랜치는 병합하지 않았고 기존 공개 사이트를 변경하지 않았다. 별도 CDN 미리보기 경로는 HTTP 403으로 검증에 실패했으므로 실행 가능한 공개 링크로 제시하지 않는다.

원경 대기감: WebGPU 경로의 체적 안개 미구현을 확인하고, 깊이 버퍼를 사용한 후처리를 추가했다. 카메라에서 100m 이내는 보존하며 그 이후 지수 함수로 원경 대비를 낮추고, 하늘 픽셀은 제외한다. 이는 대기 산란의 화면 공간 근사이며 체적 광선 추적이라고 주장하지 않는다. 이동 화면과 노이즈 제거 완료 화면에 같은 함수를 적용한다. 정지 완료 뒤에는 카메라·크기·장면 상태가 바뀔 때까지 렌더 결과를 유지하도록 했다.

[대기감 결과](evidence/cinema-atmosphere.png)에서 64샘플과 노이즈 제거 완료를 확인했다. 완료 뒤 두 관측에서 정밀 렌더 호출 수가 6500으로 유지됐고, 정면 이동 후 12615로 증가하며 다시 수렴했다. 따라서 정지 시 화면을 유지하면서 입력 후 계산을 재개함을 확인했다.

근거리 마감: 본 건물의 불투명 고금속성 재질에 고정 시드의 미세 거칠기 맵과 0.32 방향성 반사, 약한 보호 코팅을 적용했다. 코어 벽·기둥·슬래브에는 기존 석고 PBR의 법선·거칠기만 약하게 적용해 단색 면을 보완했다. 원형 부재의 정점과 변환은 수정하지 않는다.

[근거리 마감 검증](evidence/cinema-close-materials.png): 실제 휠 입력 6회로 카메라 반경을 62m에서 45.5757m로 줄인 뒤 64샘플·노이즈 제거 완료를 확인했다. 새 셰이더 오류나 정밀 렌더 실패는 없었다. 확대 상태의 상하 크롭은 줌 동작에 따른 것이며 기본 코너 버튼으로 전체 시점에 복귀한다.

WebGL 호환 모드에서도 새 재질과 HDR 환경이 표시됨을 확인했다. 기본 코너 버튼으로 기존 좌표(-44.984, 21.038, 45.343)에 복귀했다. 관측 당시 표시 프레임률은 27–39FPS였으며 이는 장치별 성능 보장을 의미하지 않는다.


## 차량 배치 오류와 맑은 주광 재검증 (2026-10-15)

사용자 피드백에 따라 형상 보존, 유리·실내, 명확한 차량 오류, 밝고 선명한 주광을 우선했다. 올 글라스 alt4의 3,234개 메시 / 119,173개 정점 및 로컬 변환 해시는 계속 `3710930476`으로 원본 기준과 같다. 다른 후보안까지 이번 검증을 확장한 것은 아니다.

- 차량 원본은 +X, 가져온 glTF는 +Z 전방이었다. 축을 먼저 정규화한 뒤 간선도로 차선 중앙과 대각선 도로 접선에 맞춰 12대를 배치했다. 오른쪽 통행과 횡단보도 이격을 적용했다. 콘셉트카의 과도한 폭도 2.1m bounding envelope로 조정했다(실제 정점 폭 약 1.97m, 길이 4.65m). 주변 차량은 실측 설계 자료가 아닌 표현용 에셋이다.
- 총 1,953,192개 차량 정점을 월드 좌표로 변환해 도로 경계와 횡단보도 침범을 검사했다. 12대 모두 통과. `evidence/vehicle-placement-audit.json`은 보정 후 결과다.
- Poly Haven Kloppenheim 05 Pure Sky를 배경과 정밀 환경광에 사용했다. 유리 투과 색을 #f3f9fc로 중립화하고 환경광을 .85로 조정했다. 먼 거리 안개 밀도를 절반으로 낮췄다. 건물 치수나 개구부 위치는 변경하지 않았다.
- 보도에 쓰던 회색 셰이더 보정은 WebGL 전용이어서 정밀 렌더에서 적용되지 않았다. 공통 재질의 선형 색 보정으로 바꾸어 양쪽 모두 밝고 중립적인 보도를 사용한다.
- 64 / 192 샘플 완료 화면을 같은 기본 카메라에서 비교했다. 192에서는 작은 디테일 차이는 있으나 실사와의 큰 차이를 해결하지 못했고 대기 시간이 증가했다. 따라서 기본 고품질은 64를 유지한다. 두 evidence 이미지의 차량 폭은 마지막 폭 보정 전이며, 도로 검사 JSON과 이후 화면이 최신이다.

개선 후에도 원본 AI 실사의 하늘 색, 주변 도시의 다양성, 실내 세부 묘사에는 차이가 남는다. 샘플 수 증가만으로 해결되는 문제가 아니므로 실사 동등 품질을 달성했다고 판정하지 않았다.


### 창호·실내 마감 비교

좁고 긴 세로 커튼월 부재만 기존 프로파일 그대로 더 짙은 새틴 금속(#66737a)으로 표현했다. 옥상 부재와 넓은 외장 부재는 이 규칙에서 제외한다. 이는 실사 참고 이미지에 맞춘 표현 검토안이며 확정 시방 변경을 의미하지 않는다. 각 층의 실내 면광원을 평면 안의 세 지점으로 분산하고, 1층은 상부층보다 밝게 조정했다. 약한 채도 보정(1.12)을 이동·정밀 화면에 공통 적용했다.

실제 정면·후면 64샘플 수렴을 확인하고 `cinema-glazing-front.png`, `cinema-glazing-back.png`로 저장했다. 형상 해시는 다시 `3710930476`으로 유지됐다. 화면의 자료 기준 안내도 현재 올 글라스·자주식3만 검증했음을 명시하고, 실제 설정과 달랐던 주변 아파트 설명을 현황 모델로 바로잡았다.


### 정지 중 미리보기 재사용

카메라가 멈춘 뒤 정밀 계산을 하는 동안 동일한 실시간 장면을 매 프레임 다시 그리던 중복 작업을 제거했다. 마지막 실시간 프레임을 2D 캔버스에 보관하고 그 아래에서 동일한 3D 장면을 계속 광선 추적한다. 움직임·크기·조명·품질·주변 건물 설정이 바뀌면 즉시 폐기한다. 이는 시점별 이미지 전환 방식이 아니며 이동 중에는 계속 실제 3D 카메라로 렌더한다.

현재 장치의 754px 창, 코너 시점에서 카메라 변경 후 64샘플 + 노이즈 제거 완료까지 16.33초를 측정했다(`preview-cache-benchmark.json`). 이전 버전과 동일 조건의 통제된 속도 비교는 아니므로 배속 개선 수치로 일반화하지 않는다. 조명 오전/오후 변경 시 캐시 픽셀이 달라지고, 비교 패널 변경으로 캔버스가 883×568에서 865×540으로 갱신되며 다시 수렴하는 것을 확인했다. 완료 시 캐시는 숨겨지고 새 정밀 결과가 표시된다.

주변 건물 숨김과 균형 품질 변경에서도 새 캐시로 갱신되어 32샘플 완료, 표시 중인 주변 건물 0개를 확인했다. 이후 주변 건물과 고품질을 복원했다. 1600px 비교 캡처는 `cinema-latest-comparison.png`에 저장하고 창 크기 강제 설정은 해제했다.


### 밝은 주간과 보도 배치 정리

같은 장면의 ACES / Neutral 톤 매핑을 실제 화면에서 비교해, 하늘의 푸른색과 밝은 중간톤을 더 잘 유지하는 Neutral + 노출 1.4를 정밀 렌더러 기본값으로 선택했다. 이 설정은 이동 중 WebGPU 화면에도 공통 적용된다. 기존 WebGL 호환 렌더러는 별도의 이전 톤 매핑을 유지한다.

가로수 높이를 9.2~10.8m로 조정하면서 코너 수관의 외벽 관통을 발견했다. 기존 코너 나무 일부가 차도 안에 배치됐던 문제도 확인해, 총 21그루의 가로수를 보도선에 맞춰 배치하고 좁은 구간의 수관을 줄였다. 식재대는 대각선 보도 방향에 맞춰 회전한다. 횡단보도 앞과 학교 진입로를 비웠으며, 차도 안에 있던 기존 보행자 3명과 가로등 한 곳도 보도로 옮겼다. 건물의 설계 메시에는 손대지 않았다.

`landscape-placement-audit.json`: 21그루와 21개 식재대 검사에서 본 건물 평면 관통, 식재대 차도 침범, 횡단보도 침범 0건. 수관은 건물 평면 외접 상자와 분리되면 조기 통과시키고, 겹칠 때만 실제 정점을 층별 평면으로 검사한다. 주변 모든 건물과 수관의 충돌 또는 실제 현장 수목을 확인한 결과는 아니다. 이번 배치는 표현용이다. 새 화면은 `cinema-bright-day-landscape.png`에 저장했다.

캐시 적용 후 실제 마우스 드래그로 수평·상하 카메라 좌표가 바뀌고 다시 수렴하는 것도 확인했다(`preview-cache-drag.json`).


### 실내 가구의 바닥 접촉과 상세 모델

기존 표현용 가구의 기준 높이 `L.y + .45`가 실제 마감 바닥(1층 +.07, 상부층 +.015)과 맞지 않아 약 38~43.5cm 떠 있던 것을 수정했다. 조명 기구도 층 기준 천장 아래로 배치하고 상부 화분의 바닥 높이를 맞췄다. 설계 모델의 바닥이나 창호 위치는 바꾸지 않았다.

Poly Haven의 Modern Arm Chair 01 (VibrantNordic, CC0, 1K PBR)을 라운지 17곳에 2개씩 사용했다. 다운로드 에셋을 저장소 안에 포함해 외부 런타임 요청을 없앴고, 로드 실패 시 기존 간단 가구를 유지한다. 의자의 전방은 +Z임을 원본 정점으로 확인했다. 모든 가구는 확정 인테리어 계획이 아닌 표현용이다.

`interior-chair-audit.json`: 의자 34개의 각 5,851개 정점을 층 평면과 비교해 외벽 밖 정점 0개, 최하단 높이 모두 마감 바닥 +3mm. 이는 의자끼리나 다른 가구와의 전체 충돌 검증을 의미하지 않는다. 건물 형상 해시는 `3710930476`으로 다시 일치했다. 코너 전체 및 저층 확대에서 64샘플 노이즈 제거 완료 화면을 확인했다(`cinema-furniture-daylight.png`, `cinema-interior-contact.png`).


### 원경 도시의 반복성 완화

단일 창문 타일을 모든 층에 반복하던 원경 외벽을 층별·창별 밝기와 블라인드 상태가 다른 고정 시드 입면으로 바꿨다. 건물 높이 범위를 넓히고 260m 밖 일부에 높은 주거동을 배치했다. 배치 중 기존 주변 매스와 이미 추가한 원경 건물을 함께 검사하여 넓은 주거동끼리 겹치지 않게 했다. 이것은 현황 설계 변경이나 서울 시가지 실측 복원이 아닌 표현용 배경이다.

일부 오피스 원경에는 ambientCG Facade019A의 1K PBR 컬러·OpenGL 노멀·거칠기·금속성 맵을 추가했다. 라이선스는 https://docs.ambientcg.com/license/ 의 CC0이며 원본 파일을 프로젝트에 포함한다. 외부 재질의 단순 색칠보다 표면·유리 반사 차이를 제공하지만 근거리 건축 디테일을 대체하지는 않는다.

환경 TextureLoader가 비동기 완료되기 전에 정밀 렌더러가 image를 복사할 수 있던 순서 문제도 수정했다. 모든 요청이 성공 또는 실패로 끝난 뒤 변환을 시작하고 실패는 경고한다. 현재 실행에서 새 맵 네 개 모두 1024×1024로 로드됨을 확인했다.

`skyline-placement-audit.json`: 원경 1,912개 매스의 월드 경계 상자 쌍 검사에서 교차 0건. 5개 유형별 945/387/149/406/25개. 검사는 원경끼리의 교차에 대한 것으로 도시 전체의 실측 정확도 증명이 아니다. 본 건물 형상 해시는 다시 `3710930476`으로 동일하다. `cinema-urban-facades.png`는 코너 64샘플 노이즈 제거 완료 화면이다. 기존 실사와 비교할 때 원경의 표면 다양성은 늘었지만 절차적 배경이라는 인상이 여전히 남아, 실사 동등 품질 판정은 보류한다.
