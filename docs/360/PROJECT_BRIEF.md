# 프로젝트 기준: 건축·인테리어 의사결정 앱의 실사 3D 모드

2026-10-16 사용자 정정 반영. 이 문서는 지속적인 목적/요구사항의 기준이며, 진행 상태는 WORK_STATE.md로 분리한다. 사용자 최신 지시가 항상 우선한다.

## 목적
기존 프로젝트에서 구조, 채광, 창과 외장, 공간/동선, 인테리어 후보를 비교하고 선택하는 판단을 돕는다. 이번 작업은 그 앱의 표현 방식에 연속 자유 시점 실사 3D를 추가하는 일이다. 별도 카페 전시/홍보 사이트를 만드는 일이 아니다.

## 가치와 불변 조건
- 확정/원본 구조와 후보안의 의미를 보존한다. 평면, 코어, 기둥, 창호, 층고, 계단, 램프, 지상/지하 관계를 보기 좋게 임의 변경하지 않는다.
- 실사 모드에서도 기존 UI의 동일 조작으로 동일 대상·후보·층·일시·표시 조건을 다룬다. 렌더 모드 전환은 설계 선택이나 사용자의 위치를 임의 초기화하지 않는다.
- 채광 판단의 신뢰성을 보존한다. 원본 날짜/시간/계절/방위의 태양 조건을 공유한다. 분위기를 위한 고정 태양이나 과도한 노출 보정으로 선택의 영향을 감추지 않는다.
- 실제 태양 계산/자료 정확도는 검증 전 보장하지 않는다. 시각적 채광 비교와 정량 조도·법규 일조 분석은 다르며, 검증 없는 lux/일조 충족 판정을 생성하지 않는다.
- 후보 비교는 같은 카메라·빛·노출 조건으로 한다. 노출 자동 변경 때문에 더 밝아 보이는 것을 창/설계 개선으로 오인하지 않게 한다.
- 기존 AI 실사 사진은 분위기/재질 참고. 서로 모순되는 구조를 정답으로 복제하지 않는다. 원본 자료로 확인한 것과 추정/제안한 것을 구분한다.
- 기존 2D 실사, 스케치업, 렌더와 관련 데이터/버튼을 보존한다. '기존 실사 사진'과 '실사 3D'의 의미를 구분한다.

## 범위: 기능 연결과 자산 완성도를 분리
기능 연결 범위는 기존 main 앱의 전체 기능군이다. 상세 항목은 VIEWER_CONTRACT.md에 기록한다. 카페만 연결하고 다른 기능은 강제로 스케치업으로 보내는 것은 임시 우회이며 완료가 아니다.
고품질 자산의 1차 제작 범위는 외관/대표 거리와1층 카페 및2개 인테리어 예시다. 다른 층의 고품질 가구가 없더라도 실제 해당 층 구조·창·채광·단면·이동 기능은 사용할 수 있는 연결 구조를 만든다. 미제작 fit-out을 '구조만 표시/상세 자산 미제작'으로 명시하고 나중에 자산만 추가할 수 있어야 한다.

## 목표 흐름
기존 앱에서 구조/외관 선택 → 같은 상태로 실사3D → 층/공간 이동·단면·창밖 보기 → 날짜/시간 및 채광 비교 → 인테리어 후보 비교 → 다른 렌더 모드/원본 사진 비교 → 외부 복귀. 이때 구조 선택과 실내 장식 선택은 독립적이다.

## 자산/빛/성능 정책
고품질 무료 모델을 우선 활용하되 공개 웹 배포 허용 라이선스·출처를 보존하고 실척·동선을 검증한다. 고정 간접광 베이크와 동적 직사광/반사를 조합하되 구조·창·배치·태양 조건이 바뀌면 유효성을 검사한다. 모든 조합의 고품질 베이크를 사전 제작하는 것은 필수가 아니나, 유효하지 않은 베이크를 조용히 유지하는 것은 금지한다. 미준비 조합에서도 동일 기능을 동작시키는 실시간 경로가 필요하다.
기본 화면은 회전 후 누적 대기 없이 일관된 품질을 목표로 한다. 정밀 렌더는 선택 기능이다. 엔진 교체는 동일 기능/상태 계약과 성능을 유지할 수 있다는 증거가 있을 때만 한다.

## 배포와 완료
가장 먼저 기존 운영본/main과 분리된 온라인 검토 환경을 만든다. 별도 배포는 제품을 별도 앱으로 만든다는 뜻이 아니라 동일 앱의 검토 버전을 격리하는 것이다.
완료에는 기능 계약 검증, 실내/외부 품질 비교, 실제 배포, 성능/입력 검증, 미완료 공개, 다음 담당자용 독립 프롬프트가 포함된다. 기능 성공으로 실사 품질 성공을 대신하지 않는다. 전체 주간50% 안에 결과/한계/인계까지 완결한다.
