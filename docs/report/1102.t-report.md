### 1. 윈도우 첫 렌더 전환

CPU 기록으로 긴 프레임 두 개를 갈랐습니다. 하나는 '렌더'를 누른 순간 Wing 반사 지도 갱신이 셰이더 약 25개를 한 프레임에 만든 것(3.7초)으로, 그 순간도 셰이더 분산 대상에 넣었습니다. 다른 하나는 지니 압구정로 단차 코드가 렌더-실사 바닥 모델을 스케치업 바닥 모델과 똑같이 처음부터 다시 자른 것(4.0초)으로, 위치가 같은 모델이면 처음 자른 결과를 재사용하게 했습니다(결과 동일, 원본 비교·램프 시험 통과).

### 2. 깜빡임

정지 상태는 13개 구성 모두 0.00% 이고, 이동량 1·2·4mm 에서 대체로 함께 커집니다(시간 누적 안티에일리어싱이 없는 한 이동 중 계단은 남음). 화면 전체 깜빡임은 가까운 의자·기둥이 먼 배경 위를 지나는 가림 경계를 배경 거리로 판정해 깜빡임으로 세던 측정 오류를 고쳐 기준 안이 되었습니다(화면은 그대로, 판정만 바뀜, 예전식은 `OLDE=1`). 바닥 깜빡임은 측정식을 그대로 두었고, 휴대폰 길 시점 먼 바닥(실행마다 1.4～2.5%)의 원인은 ② 신축에서 0.6m 내려간 연석 가장자리에 대지 다각형 옆면·건물 바닥판·Wing 지하 천장판이 1～3cm 간격으로 겹친 얇은 틈입니다. 지하 천장판 깊이 밀기는 효과가 없어 되돌렸고, 형상 정리는 하지 못했습니다.

### 3. env-school

바로 '렌더'로 들어가면 정상이고 스케치업 → 렌더(이전) → 렌더 순서로 거칠 때만 바랬습니다. 지니 `khSkMat` 이 이미 선형으로 바뀐 재질에 표시값(sRGB)을 넣고, 렌더 재진입이라 `linearize` 가 건너뛰어 sRGB 값이 선형으로 쓰인 것입니다. 1102.s 에서 지니 원본 줄을 되돌리며 다시 드러났습니다.

### 4. VR 삼각형

VR 외관에서만 창가 띠 가구(유리 너머로만 보임)를 단순화 판으로, 대지 중심 12m 밖 차량을 더 줄인 판으로 바꿉니다. 실내로 들어가면 원래 형상입니다. 머리 위치로 고르던 첫 시도는 순간이동마다 다시 합치기를 해 멈춤이 생겨 고정 기준으로 바꿨습니다. VR 실내 1층은 약 115만으로 이번 목표 밖입니다.
