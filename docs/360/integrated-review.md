## 구조

원본 state와 층 생성 코드가 설계 기준이다. 선택 상태를 같은 출처의 iframe 문서로 전달하고 이전 문서를 해제한 뒤 새 시안을 생성한다. 전달 상태가 있으면 기존 독립 뷰어의 alt4 강제를 해제한다. null에서 문자열로 바뀌는 색상 필드와 추천 시안 배열도 전달한다. 초기 설정은 원본 기본값이다. 카메라는 변경 전 정밀 화면에서 유지하며 시점 버튼은 원본 카메라의 전환을 따라간다. 실사 근사 구도 버튼도 추가했다. 시안 변경은 장면 재생성이므로 로딩 지연이 남는다.

## 참고 사례와 선택

- [PlayCanvas Orange Room](https://developer.playcanvas.com/tutorials/orange-room/): HDR lightmap과 동적 반사를 조합한 공개 시각화 사례. [실행 데모](https://playcanv.as/p/1ha5glKf/). 여기서는 시안과 층수가 바뀌므로 고정 라이트맵을 모든 설계에 재사용하지 않는다.
- [model-viewer 조명 비교](https://modelviewer.dev/examples/lightingandenv/index.html): 환경광, 배경, 노출, 톤매핑을 분리해 다룬다. Neutral 톤매핑을 유지하며 하늘과 색 보정의 동시 과장을 줄였다.
- [Three.js 물리 재질](https://threejs.org/docs/pages/MeshPhysicalMaterial.html): 투과·IOR·코팅을 구분한다. 채택안은 유리 기본 재질의 금속성을 0으로 하고 코팅 반사를 별도로 표현한다. IOR 1.8/clearcoat 1은 외관 검토 근사값이며 실제 제품의 광학 측정값이 아니다.

엔진 전환 없이 현재 WebGPU 광선 추적을 유지했다. 사례 코드를 복제하거나 새 유료 서비스를 사용하지 않았다.

## 주광 시험

1. 하늘 채움광 .55, 노출 1.15, 비금속 유리, 실내 광원 1/4 조합은 건물이 어두워져 제외했다(daylight-trial.png).
2. 기존 Kloofendal 48d HDR를 재사용했다. 해당 2K 파일의 최고 밝기 위치에서 얻은 방위각 .5967185 rad, 고도 .8360195 rad를 기준으로 하늘과 환경광을 같은 각도로 회전한다. 오전/오후 보조 태양광도 이 방향에 맞춘다. 석양은 기존 분위기 프리셋이며 현장 일조 시뮬레이션이 아니다.
3. 채택: 환경광 .8, 배경 1.55, 노출 1.4, 백색 보정 (.97,1,1.025), 채도 1.03. 실내 면광원은 기존 1/4. 상층 유리 metalness 0, IOR 1.8, clearcoat 1, roughness .025. 금속성 .42 시험은 녹색 주변 반사가 두드러져 제외했다(daylight-coated-trial.png).
4. 최종 표시의 원근 효과가 참조하는 보조 실시간 패스에도 이동 중과 같은 유리 재질 치환/복원을 적용했다. 광선 추적의 원래 재질은 복원한다. 이 보조 패스의 투과 재질이 프레임 버퍼 형식 불일치를 일으키는 경로를 수정했다.

## 앞선 색 공간 진단 정정

canvasTex 자체에는 sRGB 표시가 없지만, 실제 실행에서는 원본 setRender(true)의 linearize(true)가 이미 sRGB를 지정했다. 따라서 7c8d933의 색 공간 복제는 개선을 주지 않았다. 그 중복 코드와 검증되지 않은 농구장 재질 교체를 제거했다. 색 공간 누락을 당시 화면 문제의 원인이라고 설명한 것은 잘못된 진단이었다.

## 품질 한계

실사 AI 이미지와 동등한 품질 달성을 선언하지 않는다. 실내·후면 프레임 겹침, 일부 단순한 옥상 식재, 주변 건물 반복과 불투명 창 대용 면이 남아 있다. AI의 창 위치나 층 구조 차이에 맞추려고 설계를 변경하지 않는다. 실내 가구·식재는 예시이며 확정 설계가 아니다. 상태·층 평면 검증은 원본 코드와의 일치이지 도면 정확성 인증이 아니다. 전체 조합의 전수 시각 검사는 완료되지 않았다.


## 실행 검증

기계식·자주식2·자주식3에서 원본 state와 정밀 장면 state, 층별 key/y/h/평면 좌표가 일치했고 64샘플 완료를 확인했다. 자주식1 테라코타는 상태·평면 일치와 광선 추적 실행을 확인했다. 추천 아치 석재 및 아이보리 색상 전달도 확인했고 64샘플 실제 화면을 integrated-arch.png로 기록했다. 자주식3을 5층, 1층 층고 4.8m로 바꾼 뒤에도 원본 층 데이터와 일치하고 64샘플 완료를 확인했다. 전체 시안 조합을 전수 검사한 것은 아니다. 상세 실행 시점 기록은 integrated-state-audit.json에 있다.

현재 화면 이미지 저장은 실제 1566×1250 PNG가 표시되는 것을 확인했다. 내부 보기에서 iframe 해제·스케치업 전환·원본 내부 모드 활성화를 확인했고, 실사에서 PH.on=true와 iframe 제거를 확인했다. 실제 마우스 드래그로 카메라가 회전하는 것을 확인했다. 원본 시점 버튼은 매 프레임 정밀 카메라에 전달한다. 이동 중에는 비용이 큰 화면 공간 AO를 생략하고 정지 후 정밀 광선 추적을 유지한다.

정밀 최종 표시에서 발생하던 copyFramebufferToTexture 형식 오류를 재현하고 호출 경로를 추적한 뒤 수정했다. review-5 새 문서의 64샘플 완료 후 브라우저 오류 로그가 비어 있음을 확인했다. 기하 복사·그룹 drawRange 및 창호 중심/회전 회귀 검사와 JavaScript 구문 검사, 번들 빌드도 통과했다.


최종 review-6에서도 자주식3 올 글라스의 64샘플/노이즈 제거 완료, GPU 실패 없음, 유리 원래 재질(transmission 1 / metalness 0 / clearcoat 1) 복원을 확인했다. 정면 버튼 전환 후 부모·자식 카메라 및 target 거리 차이는 0이었다. 최종 화면은 integrated-final.png, 실사 나란히 비교는 review-daylight-final.png이며 상세 값은 integrated-final-audit.json에 기록했다. 검증 중 나타난 별도 MutationObserver 오류는 URL 없는 Electron sandbox 호출 스택이었고, 뷰어의 프레임 버퍼 오류와 구분했다.

이번 요청 시작 사용량 65%, 최종 확인 74%로 추가 약 9%포인트를 사용했다. 사용자가 허용한 추가 20%포인트 범위 내다. 공개 배포는 하지 않았으며 PR은 draft 상태다.
